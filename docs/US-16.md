# US-16: Filter Courses by Type, Season, and Difficulty

> **Status:** Implemented  
> **Story Reference:** `US-16` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Enable students to filter the Course Catalog drawer by course category (`Core` / `Area Elective` / `General`), offering season (`Fall` / `Spring`), and difficulty rating (`1`–`5`).

## Implementation

- Added `season` (`FALL`, `SPRING`, `BOTH`) to [`Course`](../src/main/java/kz/edu/sdu/advisor/model/Course.java) via migration [V8__add_course_season_column.sql](../src/main/resources/db/migration/V8__add_course_season_column.sql) and populated semester-aligned offering seasons in [`DataSeeder`](../src/main/java/kz/edu/sdu/advisor/config/DataSeeder.java) (odd semesters → `FALL`, even semesters → `SPRING`).
- Extended [`AvailableCourseDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/AvailableCourseDto.java) with `category` (`CORE`, `ELECTIVE`, `GENERAL`) and `season`.
- Extended `GET /planner/catalog` in [`PlannerController`](../src/main/java/kz/edu/sdu/advisor/controller/PlannerController.java) with optional `type`, `season`, and `difficulty` query parameters.
- Added the `General` filter chip (`data-filter="GENERAL"`), `#catalog-season-filter`, `#catalog-difficulty-filter`, and item season/difficulty badges in [planner.html](../src/main/resources/templates/planner.html), [planner.js](../src/main/resources/static/js/planner.js), and [planner.css](../src/main/resources/static/css/planner.css).

## Verification

- [PlannerControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PlannerControllerTest.java) verifies filter UI controls on `GET /planner` and combined `type`, `season`, and `difficulty` filtering on `GET /planner/catalog`.
