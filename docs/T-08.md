# T-08: Adopt Tailwind CSS Utility Layer

> **Status:** Implemented  
> **Task Reference:** `T-08` ([USER_STORY_MAP.md](USER_STORY_MAP.md)) · **ADR:** [ADR-0002](adr/0002-adopt-tailwind-css-utility-architecture.md)

## Goal

Establish a uniform utility-first CSS design system and centralized Tailwind theme token configuration across all SDU Academic Advisor screens.

## Implementation

- Added [`tailwind-utilities.css`](../src/main/resources/static/css/tailwind-utilities.css) defining consistent layout (`flex`, `grid`, `gap-*`), surface (`bg-white`, `bg-slate-50`, `bg-indigo-50`, `rounded-xl`, `shadow-md`), typography (`font-sans`, `text-*`, `font-semibold`, `antialiased`), and status badge utility classes.
- Added [`tailwind-config.js`](../src/main/resources/static/js/tailwind-config.js) exposing `window.advisorTailwindTheme` (SDU palette, fonts, radii).
- Integrated `/css/tailwind-utilities.css` and `/js/tailwind-config.js` across `login.html`, `register.html`, `registration-success.html`, `dashboard.html`, `planner.html`, `profile.html`, `faq.html`, and `advisor.html` while keeping existing DOM IDs and table structures compatible with automated tests.

## Verification

- [TailwindUiConsistencyTest.java](../src/test/java/kz/edu/sdu/advisor/ui/TailwindUiConsistencyTest.java) validates that all templates include the local Tailwind utilities & config without remote CDN URLs and render the stylesheet and utility classes properly across authenticated and public routes.
