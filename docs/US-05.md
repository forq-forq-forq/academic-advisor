# US-05: Self-Service Password Reset

> **Status:** Implemented  
> **Story Reference:** `US-05` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Enable students who forgot their password to request a secure time-limited reset token via Student ID or `@sdu.edu.kz` email, validate token expiry and single-use guarantees, and update their password cleanly across both `Student` and `StudentAccount`.

## Implementation

- Added [`PasswordResetToken`](../src/main/java/kz/edu/sdu/advisor/model/PasswordResetToken.java) (`password_reset_tokens` table) via [V6__add_password_reset_tokens_table.sql](../src/main/resources/db/migration/V6__add_password_reset_tokens_table.sql) and [`PasswordResetTokenRepository`](../src/main/java/kz/edu/sdu/advisor/repository/PasswordResetTokenRepository.java).
- Implemented [`PasswordResetService`](../src/main/java/kz/edu/sdu/advisor/service/PasswordResetService.java) with:
  - 30-minute UUID token lifetime (`TOKEN_TTL_MINUTES = 30`).
  - Automatic invalidation of previous unused tokens for the student.
  - Anti-enumeration response semantics when identifier is unknown.
  - Password strength validation (`12–64` characters, upper/lower/digit/symbol) and confirmation match before updating BCrypt hashes on both `Student` and `StudentAccount`.
- Implemented [`PasswordResetController`](../src/main/java/kz/edu/sdu/advisor/controller/PasswordResetController.java) (`/forgot-password`, `/reset-password`), templates [forgot-password.html](../src/main/resources/templates/forgot-password.html) & [reset-password.html](../src/main/resources/templates/reset-password.html), and updated [login.html](../src/main/resources/templates/login.html) & [auth.css](../src/main/resources/static/css/auth.css).

## Verification

- [PasswordResetControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PasswordResetControllerTest.java) covers `/forgot-password` anti-enumeration, single-active-token invalidation, expired/unknown token rejection, weak/mismatch rejection, dual entity BCrypt updates, single-use replay prevention, and login with the new password.
