# US-29: Completed course history

As a student, I want to see a table of my completed courses with letter grades,
credits, and semester taken, so that I can review my academic history.

## Acceptance criteria

- The authenticated dashboard shows course code, name, letter grade, credits
  (ECTS), and semester taken for every completed course, ordered by course code.
- Only the signed-in student's completed courses appear; enrolled-only courses
  and other students' history are excluded.
- Students without completions see "No completed courses yet."
- Missing grades or semesters show "Not recorded"; no grades or dates are inferred.
- The table uses column headers and a caption, escapes stored text, and scrolls
  horizontally on narrow screens.

## Implementation and data

`CourseCompletion` provides a read-only JPA view of `student_courses`, retaining
the existing `Student.completedCourses` mapping used for prerequisites and credit
totals. Nullable `letter_grade` (10 characters) and `semester_taken` (50 characters,
for example `Fall 2024`) belong to the student/course pair, never the shared course.
The existing pair represents one completion per course; repeated attempts are
outside this story. Credits use the existing course catalog value.

The dashboard takes the student ID from the authenticated session and queries by
the loaded student's database ID. No student selector is accepted from the browser.
History is read-only. There is no transcript import/editor in this story; trusted
data loading must supply recorded grades and terms. Existing/demo history displays
the missing-data fallback until those values are provided.

## Existing database upgrade

The project currently uses Hibernate `ddl-auto=update`, without a Flyway runtime.
The versioned migration `src/main/resources/db/migration/V1__completed_course_history.sql`
is provided for existing SQLite and PostgreSQL installations. Run it once against
the existing database **before** starting the upgraded application. It adds two
nullable columns and preserves every existing completion. Do not run it again if
Hibernate has already added these columns. New databases and test databases are
created from the entity mappings. Flyway is not automatically enabled by this change.

## QA

- Given a student with recorded history, opening the dashboard shows the exact
  grade, credits and semester associated with each completion.
- Given existing completions without metadata, the same courses appear with
  "Not recorded" in the grade and semester columns.
- Given an empty history, the dashboard shows the empty state.
- Given another student's history, it is absent from the signed-in student's table.
- Given a logged-out or stale session, the dashboard redirects to login.
- Given stored HTML in a semester field, it renders as escaped text.
