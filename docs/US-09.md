# US-09: Dashboard Registration Alert

> **Status:** Implemented  
> **Story Reference:** `US-09` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Surface upcoming, open, and closing-soon course registration windows directly on the student Dashboard with clear urgency styling and a direct call to action to the Course Planner.

## Implementation

- Added [`RegistrationPeriod`](../src/main/java/kz/edu/sdu/advisor/model/RegistrationPeriod.java) (`registration_periods` table via [V7__add_registration_periods_table.sql](../src/main/resources/db/migration/V7__add_registration_periods_table.sql)) and [`RegistrationPeriodRepository`](../src/main/java/kz/edu/sdu/advisor/repository/RegistrationPeriodRepository.java).
- Added [`RegistrationAlertDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/RegistrationAlertDto.java) and [`RegistrationAlertService`](../src/main/java/kz/edu/sdu/advisor/service/RegistrationAlertService.java) prioritizing open windows (`CLOSING_SOON` when ≤ 3 days left, `OPEN` otherwise) over upcoming windows (`UPCOMING` within 30 days).
- Seeded an active `"Fall 2026 Course Registration"` window (`+3` to `+17` days) in [`DataSeeder`](../src/main/java/kz/edu/sdu/advisor/config/DataSeeder.java).
- Wired `registrationAlert` into [`DashboardController`](../src/main/java/kz/edu/sdu/advisor/controller/DashboardController.java), rendered `#registration-alert-card` in [dashboard.html](../src/main/resources/templates/dashboard.html), and styled banner states in [dashboard.css](../src/main/resources/static/css/dashboard.css).

## Verification

- [RegistrationAlertServiceTest.java](../src/test/java/kz/edu/sdu/advisor/service/RegistrationAlertServiceTest.java) covers upcoming, open, closing-soon, and distant/inactive registration windows.
- [DashboardControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/DashboardControllerTest.java) verifies `#registration-alert-card` rendering on `/dashboard`.
