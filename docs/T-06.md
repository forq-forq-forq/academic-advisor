# T-06: Spring Security Authentication, RBAC & CSRF Protection

> **Status:** Implemented  
> **Task Reference:** `T-06` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Replace ad-hoc session attribute checks with `spring-boot-starter-security` filter-chain protection, Role-Based Access Control (RBAC), `CustomUserDetailsService`, and CSRF protection across mutating requests.

## Implementation

### 1. Roles & Persistence
- Added [`Role`](../src/main/java/kz/edu/sdu/advisor/model/Role.java) (`STUDENT`, `ADVISOR`, `ADMIN`) with `asAuthority()` (`ROLE_*`).
- Added `role` column (default `STUDENT`) on [`Student`](../src/main/java/kz/edu/sdu/advisor/model/Student.java) and [`StudentAccount`](../src/main/java/kz/edu/sdu/advisor/model/StudentAccount.java), backed by additive migration [V4__add_role_and_security_columns.sql](../src/main/resources/db/migration/V4__add_role_and_security_columns.sql).

### 2. Security Configuration & Session Bridging
- Replaced `spring-security-crypto` with `spring-boot-starter-security` and added `spring-security-test` in [pom.xml](../pom.xml).
- Added [`CustomUserDetailsService`](../src/main/java/kz/edu/sdu/advisor/security/CustomUserDetailsService.java) loading users by student ID or SDU email and assigning `ROLE_*` authorities.
- Added [`SessionSecurityAuthenticationFilter`](../src/main/java/kz/edu/sdu/advisor/security/SessionSecurityAuthenticationFilter.java) bridging authenticated HTTP session attributes (`authenticatedStudentId`) into `SecurityContextHolder` before authorization filters run.
- Updated [`AuthSessionHelper`](../src/main/java/kz/edu/sdu/advisor/service/AuthSessionHelper.java) and [`AuthController`](../src/main/java/kz/edu/sdu/advisor/controller/AuthController.java) to synchronize `SecurityContextHolder`, `SPRING_SECURITY_CONTEXT`, and session teardown on `/logout`.
- Configured [`SecurityConfig`](../src/main/java/kz/edu/sdu/advisor/config/SecurityConfig.java) with `@EnableWebSecurity`, `@EnableMethodSecurity`, public auth/static asset routes, `.requestMatchers("/advisor/**").hasAnyRole("ADVISOR", "ADMIN")`, security headers (`X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`), custom unauthenticated entry points (`/login` redirect for HTML, `401` JSON for API routes), and `advisor.security.csrf.strict=true` in `application.properties` (`false` in `application-test.properties` unless explicitly triggered via `X-Enforce-Csrf: true` or CSRF tokens).
- Added [`AdvisorController`](../src/main/java/kz/edu/sdu/advisor/controller/AdvisorController.java) (`/advisor`) with `@PreAuthorize("hasAnyRole('ADVISOR', 'ADMIN')")` and [advisor.html](../src/main/resources/templates/advisor.html).

## Verification

- [SecurityConfigTest.java](../src/test/java/kz/edu/sdu/advisor/security/SecurityConfigTest.java) verifies unauthenticated redirects & `401` JSON responses, `STUDENT` vs `ADVISOR`/`ADMIN` RBAC enforcement on `/advisor`, CSRF enforcement/acceptance, `CustomUserDetailsService` lookup, security headers, and login/logout lifecycle.
