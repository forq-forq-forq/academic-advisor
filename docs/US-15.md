# US-15: Slide-Out Course Catalog Drawer & Live Search

> **Status:** Implemented  
> **Story Reference:** `US-15` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Enable students on `/planner` to toggle a slide-out course catalog drawer and search available courses by course code or course title without leaving the planner workspace.

## Implementation

- Refactored [`PlannerController`](../src/main/java/kz/edu/sdu/advisor/controller/PlannerController.java) to extract `buildAvailableCourses(Student, CartDto)` and added `GET /planner/catalog?q=...` returning matching [`AvailableCourseDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/AvailableCourseDto.java) records filtered case-insensitively by code or title.
- Updated [planner.html](../src/main/resources/templates/planner.html) with the planner workspace toolbar (`#btn-toggle-catalog-drawer`), collapsible `#catalog-drawer`, live match count badge (`#catalog-match-count`), clear-search button (`#btn-clear-catalog-search`), and empty-match state (`#catalog-empty-state`).
- Added `toggleCatalogDrawer`, `clearCatalogSearch`, and live counter/empty-state handling in [planner.js](../src/main/resources/static/js/planner.js) along with drawer styling in [planner.css](../src/main/resources/static/css/planner.css).

## Verification

- [PlannerControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PlannerControllerTest.java) verifies slide-out catalog drawer markup on `/planner`, code/title filtering on `GET /planner/catalog`, and `401` JSON handling for unauthenticated requests.
