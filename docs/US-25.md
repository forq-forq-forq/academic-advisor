# US-25: GPA Planner & Cumulative GPA Simulator

> **Status:** Implemented  
> **Story Reference:** `US-25` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Provide a dedicated `/gpa` simulator where students select expected letter grades (`A` through `F`) for upcoming courses in their Semester Cart or enrolled load and immediately preview their projected semester GPA, cumulative GPA, and GPA delta.

## Implementation

- Added [`GpaSimulationItemDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/GpaSimulationItemDto.java), [`GpaSimulationResultDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/GpaSimulationResultDto.java), and [`GpaSimulationService`](../src/main/java/kz/edu/sdu/advisor/service/GpaSimulationService.java) using the SDU Handbook 2026–2027 grade scale.
- Added [`GpaController`](../src/main/java/kz/edu/sdu/advisor/controller/GpaController.java) exposing `GET /gpa` and `POST /gpa/simulate` (`@ResponseBody`), and updated [`SecurityConfig`](../src/main/java/kz/edu/sdu/advisor/config/SecurityConfig.java) to return `401` JSON errors for unauthenticated `/gpa/simulate` calls.
- Added [gpa.html](../src/main/resources/templates/gpa.html), [gpa.css](../src/main/resources/static/css/gpa.css), and [gpa.js](../src/main/resources/static/js/gpa.js), plus `GPA Planner` navigation links across `dashboard.html`, `planner.html`, `profile.html`, and `faq.html`.

## Verification

- [GpaSimulationServiceTest.java](../src/test/java/kz/edu/sdu/advisor/service/GpaSimulationServiceTest.java) validates credit-weighted projected cumulative GPA calculation and invalid grade rejection.
- [GpaControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/GpaControllerTest.java) verifies auth protection, `/gpa` template rendering, and `POST /gpa/simulate` JSON calculations.
