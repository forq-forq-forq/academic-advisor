# US-23: Export Semester Plan & 4-Year Roadmap as PDF

> **Status:** Implemented  
> **Story Reference:** `US-23` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Allow students to download a PDF summary of their current Semester Cart and/or 4-Year Degree Roadmap containing course codes, titles, ECTS credits, and workload summary.

## Implementation

- Added [`PlanPdfExportService`](../src/main/java/kz/edu/sdu/advisor/service/PlanPdfExportService.java) implementing a pure-Java multi-page PDF 1.4 binary writer (`%PDF-1.4` / `xref` / `%%EOF`) with automatic line wrapping and pagination.
- Added `GET /planner/export/pdf` (`produces = application/pdf`, `scope = cart | roadmap | all`) in [`PlannerController`](../src/main/java/kz/edu/sdu/advisor/controller/PlannerController.java).
- Added `#btn-export-pdf` and `#btn-export-roadmap-pdf` download actions in [planner.html](../src/main/resources/templates/planner.html) and [planner.css](../src/main/resources/static/css/planner.css).

## Verification

- [PlanPdfExportServiceTest.java](../src/test/java/kz/edu/sdu/advisor/service/PlanPdfExportServiceTest.java) verifies valid PDF 1.4 binary markers, student metadata, course codes, credits, and workload summary.
- [PlannerControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PlannerControllerTest.java) verifies `application/pdf` response headers, filename attachment disposition, and PDF body contents on `GET /planner/export/pdf`.
