# US-22: Save Multiple Named Plan Drafts

> **Status:** Implemented  
> **Story Reference:** `US-22` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Enable students to save multiple named planning scenarios (e.g., `"Safe plan"` vs `"Ambitious plan"`), review them on both `/planner` and `/profile`, restore any draft into their workspace, and delete old drafts.

## Implementation

- Added [`PlanDraft`](../src/main/java/kz/edu/sdu/advisor/model/PlanDraft.java) (`plan_drafts` table via [V10__add_plan_drafts_table.sql](../src/main/resources/db/migration/V10__add_plan_drafts_table.sql)), [`PlanDraftRepository`](../src/main/java/kz/edu/sdu/advisor/repository/PlanDraftRepository.java), [`PlanDraftDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/PlanDraftDto.java), [`LoadedPlanDraftDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/LoadedPlanDraftDto.java), and [`PlanDraftService`](../src/main/java/kz/edu/sdu/advisor/service/PlanDraftService.java).
- Added `GET /planner/drafts`, `POST /planner/drafts/save`, `POST /planner/drafts/{draftId}/load`, and `POST /planner/drafts/{draftId}/delete` in [`PlannerController`](../src/main/java/kz/edu/sdu/advisor/controller/PlannerController.java).
- Wired `planDrafts` into [`ProfileController`](../src/main/java/kz/edu/sdu/advisor/controller/ProfileController.java) and rendered `#plan-drafts-panel` in [planner.html](../src/main/resources/templates/planner.html) and `#profile-plan-drafts-section` in [profile.html](../src/main/resources/templates/profile.html).

## Verification

- [PlanDraftServiceTest.java](../src/test/java/kz/edu/sdu/advisor/service/PlanDraftServiceTest.java) verifies saving multiple named drafts (`Safe plan` vs `Ambitious plan`), restoring cart contents, and deleting drafts.
- [PlannerControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PlannerControllerTest.java) and [ProfileControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/ProfileControllerTest.java) verify API endpoints and UI rendering on `/planner` and `/profile`.
