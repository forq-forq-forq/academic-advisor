# US-18: 8-Semester Multi-Year Roadmap View

> **Status:** Implemented  
> **Story Reference:** `US-18` ([USER_STORY_MAP.md](USER_STORY_MAP.md))

## Goal

Provide an interactive 8-semester degree roadmap board on `/planner` displaying all 8 semesters with completed, enrolled, and planned curriculum courses as cards.

## Implementation

- Added [`RoadmapItem`](../src/main/java/kz/edu/sdu/advisor/model/RoadmapItem.java) (`roadmap_items` table via [V9__add_roadmap_items_table.sql](../src/main/resources/db/migration/V9__add_roadmap_items_table.sql)) and [`RoadmapItemRepository`](../src/main/java/kz/edu/sdu/advisor/repository/RoadmapItemRepository.java).
- Added [`RoadmapBoardDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/RoadmapBoardDto.java), [`RoadmapSemesterDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/RoadmapSemesterDto.java), [`RoadmapCourseCardDto`](../src/main/java/kz/edu/sdu/advisor/model/dto/RoadmapCourseCardDto.java), and [`RoadmapService`](../src/main/java/kz/edu/sdu/advisor/service/RoadmapService.java) to initialize and load all 8 semesters from completed courses, enrolled courses, cart items, core curriculum requirements, and career-aligned electives.
- Added `GET /planner/roadmap` and model attribute `roadmap` in [`PlannerController`](../src/main/java/kz/edu/sdu/advisor/controller/PlannerController.java).
- Added `#tab-cart-view` / `#tab-roadmap-view` switcher tabs and `#roadmap-board-section` (`#roadmap-semester-1`..`#roadmap-semester-8`) in [planner.html](../src/main/resources/templates/planner.html), [planner.js](../src/main/resources/static/js/planner.js), and [planner.css](../src/main/resources/static/css/planner.css).

## Verification

- [RoadmapServiceTest.java](../src/test/java/kz/edu/sdu/advisor/service/RoadmapServiceTest.java) verifies initialization of all 8 semesters and placement of completed/enrolled/planned courses.
- [PlannerControllerTest.java](../src/test/java/kz/edu/sdu/advisor/controller/PlannerControllerTest.java) verifies `#roadmap-board-section` rendering on `/planner` and `GET /planner/roadmap`.
